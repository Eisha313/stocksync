## Introduction

StockSync is a lightweight inventory alert system designed for store owners who need to stay on top of their stock levels. The system monitors your inventory in real-time and notifies you when products run low.

### Key Features

- **Real-time Monitoring**: Automatic tracking of stock levels
- **Customizable Alerts**: Set different threshold levels for each product
- **Multiple Notification Channels**: Email and SMS (premium) notifications
- **Simple Dashboard**: Easy-to-use interface for managing products

## Managing Products

### Adding a New Product

1. Navigate to the Products page
2. Click "Add Product"
3. Fill in the required fields:
   - **Name**: Product name (required)
   - **SKU**: Unique product identifier (required)
   - **Category**: Product category for organization
   - **Quantity**: Current stock level
   - **Price**: Product price

### Updating Stock Levels

You can update stock levels in several ways:

1. **Manual Update**: Edit the product directly
2. **Bulk Import**: Upload a CSV file with updated quantities
3. **API Integration**: Use our API for automated updates

### Product Categories

Organize your products into categories for easier management:

- Electronics

- Food & Beverage
- Home & Garden
- Other

## Setting Up Alerts

### Alert Levels

StockSync supports three alert levels:

| Level | Color | Description |
|-------|-------|-------------|
| Low | Yellow | Stock is getting low, consider reordering |
| Critical | Orange | Stock is critically low, reorder soon |
| Out of Stock | Red | No stock remaining, urgent action needed |

### Creating an Alert Rule

1. Go to Alerts > Create Alert
2. Select the product(s) to monitor
3. Set the threshold value
4. Choose the alert level
5. Select notification channels
6. Save the alert rule

### Alert Notifications

#### Email Notifications (Free)

Email notifications are included in the free tier:

- Instant alerts when thresholds are crossed
- Daily summary of all alerts
- Weekly inventory reports

#### SMS Notifications (Premium)

Upgrade to premium for SMS notifications:

- Instant SMS alerts
- Priority delivery
- Custom message templates

### Acknowledging Alerts

When you receive an alert:

1. Review the alert details
2. Take appropriate action (reorder, update stock, etc.)
3. Mark the alert as acknowledged
4. Add optional notes for record-keeping
